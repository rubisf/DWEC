1. Fundamentos de la Comunicación Asíncrona Cliente-Servidor (AJAX)

💡 Fundamentos Conceptuales

La web moderna se basa en la comunicación asíncrona entre el navegador y los servidores web mediante el modelo AJAX (Asynchronous JavaScript and XML):

  • Modelo Síncrono Tradicional vs Modelo Asíncrono AJAX:
    • Modelo Tradicional (Síncrono): Cada interacción del usuario (como enviar un formulario o hacer clic en un enlace) requiere solicitar una página HTML completa al servidor. La pantalla se queda en blanco temporalmente, se descarga todo el documento de nuevo y se pierde el estado visual previo de la aplicación.
    • Modelo AJAX (Asíncrono): Las peticiones de datos se transmiten en segundo plano (background) sin bloquear la interfaz de usuario ni recargar la página. El servidor responde únicamente con datos en bruto (habitualmente JSON), y JavaScript actualiza de forma granular exclusivamente la sección del DOM afectada.
  • El Ciclo de Petición-Respuesta HTTP/HTTPS:

    Protocolo sin estado cliente-servidor compuesto por:

    • Petición (Request): Método/Verbo HTTP, URL de destino, Cabeceras (Headers: Content-Type, Authorization) y Cuerpo opcional (Payload/Body).
    • Respuesta (Response): Código de estado HTTP, Cabeceras del servidor y Cuerpo con los datos.
  • Métodos HTTP RESTful Principales:
    • GET: Recuperar o consultar recursos sin alterar el estado en el servidor (idempotente y seguro).
    • POST: Crear un nuevo recurso en el servidor con los datos facilitados en el cuerpo.
    • PUT: Reemplazar completamente un recurso existente.
    • PATCH: Actualizar parcialmente campos específicos de un recurso existente.
    • DELETE: Eliminar un recurso del servidor.
  • Códigos de Estado HTTP Fundamentales:
    • 2xx (Éxito): 200 OK, 201 Created (creación exitosa), 204 No Content (éxito sin cuerpo de respuesta).
    • 3xx (Redirección): 301 Moved Permanently, 304 Not Modified (recurso en caché).
    • 4xx (Error de Cliente): 400 Bad Request (datos incorrectos), 401 Unauthorized (requiere autenticación), 403 Forbidden (sin permisos), 404 Not Found (recurso inexistente), 422 Unprocessable Entity (fallo de validación).
    • 5xx (Error de Servidor): 500 Internal Server Error, 502 Bad Gateway, 503 Service Unavailable.
🔍 Ampliación y Estándares 2026

De AJAX Clásico a la Arquitectura SPA y JAMstack:

  • La Revolución de las Single Page Applications (SPA): Al independizar la obtención de datos del renderizado HTML, las aplicaciones web funcionan con la misma fluidez e inmediatez que una aplicación nativa de escritorio o móvil, comunicándose exclusivamente mediante APIs RESTful o GraphQL.
  • Idempotencia en APIs REST: Métodos como GET, PUT y DELETE son idempotentes (ejecutarlos múltiples veces produce el mismo resultado en el servidor). POST no es idempotente (repetirlo genera múltiples recursos duplicados).

function procesarRespuestaServidor(respuesta) {
    const status = respuesta.status;
    const familiaCodigo = Math.floor(status / 100);
    const contentType = respuesta.headers?.["Content-Type"] || "desconocido";

    let diagnostico = {
        status,
        statusText: respuesta.statusText || "Sin descripción",
        contentType,
        esExito: false,
        categoria: "",
        mensajeUsuario: ""

            diagnostico.categoria = "3xx - Redirección";
            diagnostico.mensajeUsuario = "El recurso ha sido reubicado.";
            break;
        case 4:
            diagnostico.categoria = "4xx - Error de Cliente";
            diagnostico.mensajeUsuario = status === 404

            diagnostico.categoria = "Código Desconocido";
            diagnostico.mensajeUsuario = "Respuesta de red no estandarizada.";

2. Objetos y Métodos para la Comunicación Asíncrona: XMLHttpRequest vs Fetch API

💡 Fundamentos Conceptuales

JavaScript ofrece dos APIs nativas para la comunicación asíncrona: el objeto clásico XMLHttpRequest y la moderna Fetch API:

  • El Objeto Clásico XMLHttpRequest (XHR):

    API original introducida por Microsoft y estandarizada por W3C. Basada en eventos y estados:

    • Creación: const xhr = new XMLHttpRequest();
    • Configuración: xhr.open(metodo, url, esAsincrono);
    • Cabeceras: xhr.setRequestHeader("Content-Type", "application/json");
    • Envío: xhr.send(cuerpo);
    • Propiedad xhr.readyState (Estados de 0 a 4): 0 (UNSENT), 1 (OPENED), 2 (HEADERS_RECEIVED), 3 (LOADING), 4 (DONE).
    • Evento de escucha: xhr.onreadystatechange o xhr.onload.
    • Inconvenientes: Sintaxis verbosa basada en callbacks que provocaba Callback Hell en llamadas encadenadas.
  • La API Moderna Fetch API (Estándar W3C/WHATWG):

    Reemplazo moderno basado en Promesas de ES6 que permite una sintaxis imperativa limpia mediante async / await:

    • Invocación básica: const respuesta = await fetch(url, opciones);
    • Opciones de configuración: method, headers, body (usualmente JSON.stringify(datos)), mode: 'cors', credentials: 'include'.
    • Lectura del cuerpo según formato:
      • await respuesta.json(): Parsea el cuerpo directamente a objeto JavaScript.
      • await respuesta.text(): Lee el cuerpo como texto plano o XML.
      • await respuesta.blob(): Descarga ficheros binarios (imágenes, PDFs).
    • ⚠️ La Gran Trampa de Fetch: Fetch NO rechaza la Promesa en códigos de error HTTP como 404 o 500 (solo la rechaza si hay un fallo físico de red o DNS). Por ello, es obligatorio comprobar siempre la propiedad booleana if (!respuesta.ok) throw new Error(...).
🔍 Ampliación y Estándares 2026

Cancelación de Peticiones Fetch con AbortController:

  • Control de Timeouts Nativos: Fetch no posee un parámetro nativo de timeout. La forma estándar de cancelarla tras un tiempo límite es asociar un AbortController: fetch(url, { signal: AbortSignal.timeout(5000) }), cancelando la petición automáticamente si el servidor tarda más de 5 segundos.
  • Streaming de Respuestas: Fetch soporta response.body.getReader() para procesar flujos continuos de datos (Streaming) en tiempo real conforme van llegando del servidor.
💻 Demostración Práctica e Implementación de Código

async function obtenerUsuariosAPI() {
    const url = "https://jsonplaceholder.typicode.com/users";

    try {
        console.log("Iniciando petición con Fetch API...");
        const respuesta = await fetch(url, {
            method: "GET",
            headers: { "Accept": "application/json" }
        });

        // Comprobación OBLIGATORIA de respuesta.ok (código en rango 200-299)
        if (!respuesta.ok) {
            throw new Error(`Fallo en respuesta HTTP: ${respuesta.status} ${respuesta.statusText}`);
        }

        const usuarios = await respuesta.json();
        console.log(`✅ Obtenidos ${usuarios.length} usuarios con éxito.`);
        console.table(usuarios.slice(0, 3));
        return usuarios;

    } catch (error) {
        console.error("❌ Error en la comunicación asíncrona:", error.message);
        throw error;
    } finally {
        console.log("Ciclo de petición Fetch finalizado.");
    }
}

// 1. Implementación clásica con XMLHttpRequest encapsulada en Promesa
function consultarConXHR(url) {
    return new Promise((resolve, reject) => {
        const xhr = new XMLHttpRequest();
        xhr.open("GET", url, true);
        xhr.setRequestHeader("Accept", "application/json");

        xhr.onload = () => {
            if (xhr.status >= 200 && xhr.status < 300) {
                try {
                    const datos = JSON.parse(xhr.responseText);
                    resolve({ motor: "XMLHttpRequest", status: xhr.status, datos });
                } catch (e) {
                    reject(new Error("Error al parsear JSON en XHR: " + e.message));
                }
            } else {
                reject(new Error(`Error XHR [${xhr.status}]: ${xhr.statusText}`));
            }
        };

        xhr.onerror = () => reject(new Error("Fallo de red a nivel de socket en XHR."));
        xhr.send();
    });
}

// 2. Implementación moderna con Fetch API y Async/Await
async function consultarConFetch(url) {
    try {
        const respuesta = await fetch(url, { headers: { "Accept": "application/json" } });
        
        if (!respuesta.ok) {
            throw new Error(`Error Fetch [${respuesta.status}]: ${respuesta.statusText}`);
        }

        const datos = await respuesta.json();
        return { motor: "Fetch API", status: respuesta.status, datos };
    } catch (error) {
        throw new Error("Fallo en cliente Fetch: " + error.message);
    }
}

3. Formatos de Envío y Recepción de Datos: JSON, XML y FormData

💡 Fundamentos Conceptuales

El intercambio de información en la web utiliza formatos estructurados de serialización que condicionan el tamaño del mensaje y su facilidad de procesamiento:

  • Formato JSON (JavaScript Object Notation):

    El estándar absoluto en la web moderna. Ligero, compacto y nativo para JavaScript:

    • Tipos válidos: Cadenas (con comillas dobles obligatorias "clave"), números, booleanos, arrays, objetos anidados y null. No admite funciones, comentarios ni valores undefined.
    • Serialización: JSON.stringify(objeto, sustituto, sangria): Convierte objetos en memoria a cadenas para envío HTTP.
    • Deserialización: JSON.parse(cadenaTexto): Parsea una cadena JSON a objetos vivos. Arroja SyntaxError si la cadena está malformada (requiere try/catch).
  • Formato XML (eXtensible Markup Language):

    Formato clásico basado en etiquetas jerárquicas extensibles. Más pesado debido a las etiquetas de apertura y cierre duplicadas:

    • Procesamiento en Cliente: Se parsea mediante la API nativa const doc = new DOMParser().parseFromString(xmlString, "text/xml");.
    • Navegación: El documento resultante se navega exactamente igual que el DOM HTML, utilizando métodos como doc.getElementsByTagName("item") y nodo.textContent.
  • Objeto FormData (Transmisión Multipart):

    Diseñado específicamente para el envío de formularios complejos y transferencia binaria de ficheros (multipart/form-data):

    • Creación: const fd = new FormData();
    • Añadir campos: fd.append("usuario", "marcos"); fd.append("avatar", inputFichero.files[0]);
    • Al enviar con fetch(url, { method: "POST", body: fd }), el navegador configura automáticamente la cabecera Content-Type: multipart/form-data; boundary=.... Jamás se debe sobreescribir esa cabecera manualmente.
🔍 Ampliación y Estándares 2026

El Reemplazador y Revividor en JSON:

  • JSON.parse con Función Reviver: Permite transformar datos durante el parseo, como convertir automáticamente cadenas de fecha ISO a objetos nativos new Date(): JSON.parse(texto, (k, v) => /^\d{4}-\d{2}-\d{2}/.test(v) ? new Date(v) : v).
  • JSON.stringify con Indentación: JSON.stringify(datos, null, 2) formatea la salida con sangría de 2 espacios, esencial para exportación de ficheros y depuración visual.

// Conversor de XML a Objetos JSON
function xmlAJson(cadenaXML) {
    const parser = new DOMParser();
    const doc = parser.parseFromString(cadenaXML, "text/xml");
    
    // Comprobación de errores de parseo XML
    const parseError = doc.querySelector("parsererror");
    if (parseError) {
        throw new Error("Sintaxis XML defectuosa: " + parseError.textContent);
    }

    const estudiantesXML = doc.getElementsByTagName("estudiante");
    const resultado = [];

    for (const est of estudiantesXML) {
        resultado.push({
            id: Number(est.getAttribute("id")),
            nombre: est.getElementsByTagName("nombre")[0]?.textContent || "",
            nota: Number(est.getElementsByTagName("nota")[0]?.textContent || 0)
        });
    }

    return resultado;
}

function jsonAXml(estudiantes) {

        xml += `    <nota>${est.nota}</nota>\\n`;
        xml += `  </estudiante>\\n`;
    }
    
    xml += '</estudiantes>';
    return xml;
}

4. Modificación Dinámica del DOM con Datos Asíncronos y Estados de UI

💡 Fundamentos Conceptuales

La obtención de datos remotos exige una gestión escrupulosa de la experiencia de usuario (UX) mediante el control explícito de los cuatro estados de la interfaz:

  • Los 4 Estados Fundamentales de la Interfaz Asíncrona (UI States):
    • 1. Estado Inicial / Vacío (Empty State): Mensaje o ilustración informativa cuando no hay datos disponibles o la búsqueda aún no se ha iniciado.
    • 2. Estado de Carga (Loading State): Indicador visual activo (spinner circular o Skeleton Loading Screens) que informa al usuario de que la petición está en curso y evita que el usuario pulse múltiples veces.
    • 3. Estado de Éxito (Success State): Renderizado de los datos recibidos mediante plantillas literales o creación segura de nodos DOM.
    • 4. Estado de Error (Error State): Mensaje comprensible que explica el motivo del fallo y ofrece un botón interactivo de reintento (Retry) sin recargar la página.
  • Skeleton Screens frente a Spinners: Las pantallas de esqueleto (tarjetas provisionales con fondo animado simulando texto y fotos) reducen la sensación subjetiva de tiempo de espera percibido frente a los spinners tradicionales.

class HttpClient {
    constructor(baseURL = "", timeoutMs = 5000) {
        this.baseURL = baseURL.replace(/\\/$/, "");
        this.timeoutMs = timeoutMs;
        this.tokenAuth = null;
    }

    setToken(token) {
        this.tokenAuth = token;
    }

    async get(endpoint) {
        const urlCompleta = this.baseURL + "/" + endpoint.replace(/^\\//, "");
        
        // Configuración de cabeceras (Interceptor)
        const headers = { "Accept": "application/json" };
        if (this.tokenAuth) {
            headers["Authorization"] = `Bearer ${this.tokenAuth}`;
        }

        try {
            // Cancelación nativa con AbortSignal por timeout
            const respuesta = await fetch(urlCompleta, {
                method: "GET",
                headers,
                signal: AbortSignal.timeout(this.timeoutMs)
            });

            if (!respuesta.ok) {
                const error = new Error(`Error HTTP ${respuesta.status}: ${respuesta.statusText}`);
                error.status = respuesta.status;
                throw error;
            }

            const data = await respuesta.json();
            return { data, status: respuesta.status };

        } catch (error) {
            if (error.name === "TimeoutError") {
                console.error(`⏱️ Petición cancelada: Superó el tiempo límite de ${this.timeoutMs}ms.`);
            }
            throw error;
        }
    }
}

6. Angular como Framework Frontend SPA: Conceptos Clave, Componentes Standalone y Servicios Inyectables

💡 Fundamentos Conceptuales

Angular es un framework integral y profesional mantenido por Google para la construcción de aplicaciones web de una sola página (SPA - Single Page Application). A diferencia de librerías ligeras, Angular ofrece una solución "todo incluido" (servicios, enrutador, formularios y comunicación HTTP integrados de fábrica):

  • ¿Qué es un Componente y cómo funciona el Decorador `@Component`?

    Un componente es la unidad fundamental para construir la interfaz. Combina tres elementos principales: la vista HTML (plantilla), la apariencia visual CSS y la lógica TypeScript. El decorador `@Component` es una anotación especial (comienza por `@`) que se coloca justo encima de la clase TypeScript para indicarle a Angular que esa clase actuará como un componente visual con metadatos específicos:

    • selector: 'app-producto-lista': Define la etiqueta HTML personalizada con la que podemos insertar este componente dentro de otras vistas (ej. <app-producto-lista></app-producto-lista>).
    • template / templateUrl: El marcado HTML que renderiza el componente.
    • standalone: true: Indica que el componente es autónomo y no requiere registrarse en un NgModule antiguo.
  • ¿Qué son los Componentes Autónomos (Standalone Components)?

    En versiones anteriores de Angular era necesario declarar cada componente dentro de archivos organizadores de módulos llamados NgModule. En Angular moderno (v17/v18), los componentes son Standalone: autónomos y autosuficientes. Cada componente declara directamente qué librerías o directivas necesita importar mediante su propiedad imports: [CommonModule, RouterLink].

  • Sintaxis de Control Flow Nativa (`@if`, `@for`, `@switch`):

    En Angular v17+, la plantilla HTML cuenta con estructuras de control de flujo nativas y elegantes:

    • @if (condicion) { ... } @else { ... }: Muestra u oculta bloques HTML de forma condicional según el estado de las variables.
    • @for (item of lista; track item.id) { ... }: Repite un fragmento HTML iterando sobre un array de datos (ej. tarjetas de productos). La cláusula track item.id permite a Angular identificar cada elemento de forma ultra rápida al actualizar la vista.
  • Data Binding (Enlace de Datos entre TypeScript y HTML):
    • Interpolación {{ variable }}: Imprime el valor de una variable de TypeScript directamente en el marcado HTML.
    • Property Binding [propiedad]="variable": Envía datos de la clase a un atributo o propiedad del DOM (ej. [src]="producto.imagenUrl").
    • Event Binding (evento)="metodo()": Captura eventos del usuario (clics, teclas) y ejecuta funciones en TypeScript (ej. (click)="anadirAlCarrito(p)").
  • Servicios e Inyección de Dependencias (DI - Dependency Injection):

    Los Servicios son clases TypeScript marcadas con el decorador @Injectable({ providedIn: 'root' }) destinadas a gestionar la lógica de negocio y las llamadas a APIs REST. La Inyección de Dependencias (DI) es el mecanismo por el cual el componente no crea los servicios con new MiServicio(), sino que le solicita a Angular que se los suministre automáticamente a través de su constructor: constructor(private productosService: ProductosService) {}. Esto garantiza una única instancia compartida (Singleton) y un código totalmente desacoplado.

🔍 Ampliación y Estándares 2026

Herramientas de Angular CLI y Reactividad Moderna (Signals & RxJS):

  • Angular CLI (Command Line Interface): Herramienta oficial de consola para crear proyectos (ng new tienda-angular --standalone), generar componentes (ng g c componentes/navbar) y crear servicios (ng g s servicios/productos).
  • Angular Signals vs RxJS: Angular v16+ introduce Signals (const contador = signal(0);) para una reactividad ultra granular en plantillas. Para flujos de peticiones asíncronas HTTP a servidores remotos, se utilizan Observables del módulo RxJS.

Conceptos Avanzados de Enrutamiento y Peticiones Asíncronas con HttpClient:

  • ¿Qué es `router-outlet`? Es una directiva especial suministrada por `RouterModule` que sirve como área de renderizado dinámico donde Angular destruye e inserta el componente correspondiente a la URL actual sin parpadeos.
  • ¿Qué es `ActivatedRoute`? Es un servicio inyectable que proporciona acceso a la información de la ruta asociada con el componente cargado en el marcador de posición, permitiendo extraer parámetros dinámicos (como `:id`), query params y datos de estado de la navegación.
  • Consumo de APIs REST con `HttpClient`: En lugar de datos en memoria, `ProductosService` utiliza `HttpClient` (registrado con `provideHttpClient()`) para comunicarse con servidores backend asíncronos devolviendo `Observables` de RxJS.

8. Compatibilidad entre Navegadores, Políticas de Seguridad CORS y Pruebas con DevTools

💡 Fundamentos Conceptuales

La comunicación asíncrona está fuertemente condicionada por políticas de seguridad del navegador y requiere herramientas de auditoría en red:

  • La Política de Mismo Origen (Same-Origin Policy - SOP):

    Mecanismo fundamental de seguridad del navegador. Prohíbe que un script ejecutado en el origen A (ej. http://midominio.com:80) acceda libremente a los recursos o datos de un origen B diferente (distinto protocolo, dominio o puerto).

  • CORS (Cross-Origin Resource Sharing):

    Estándar que permite a los servidores autorizar selectivamente peticiones procedentes de orígenes cruzados mediante cabeceras HTTP específicas:

    • Access-Control-Allow-Origin: * (o dominio específico https://mi-frontend.es).
    • Access-Control-Allow-Methods: GET, POST, PUT, DELETE, OPTIONS.
    • Access-Control-Allow-Headers: Content-Type, Authorization.
  • Peticiones Preflight (Vuelo Previo con OPTIONS):

    Para peticiones complejas (ej. aquellas que usan métodos PUT/DELETE o cabeceras personalizadas como Content-Type: application/json), el navegador envía automáticamente una petición previa invisible con el método OPTIONS para consultar si el servidor autoriza la operación antes de transmitir la petición real.

  • Auditoría y Pruebas en DevTools (Panel Network / Red):
    • Filtro Fetch/XHR: Aísla exclusivamente las peticiones asíncronas ignorando imágenes y CSS.
    • Inspección de Headers y Payload: Verificación de cabeceras de petición, cabeceras de respuesta y cuerpos JSON transmitidos.
    • Gráfico en Cascada (Waterfall): Análisis de tiempos: DNS Lookup, TCP Handshake, SSL/TLS, TTFB (Time to First Byte) y tiempo de descarga del contenido.
    • Simulación de Condiciones Hostiles: Modo Offline (sin conexión) y Throttling de velocidad (Fast 3G, Slow 3G) para verificar la robustez de los spinners y mensajes de error.
🔍 Ampliación y Estándares 2026

Técnicas Profesionales de Mocking de APIs:

  • Mock Service Worker (MSW): Herramienta estándar que utiliza Service Workers para interceptar las peticiones Fetch a nivel de red en el navegador, devolviendo datos simulados sin necesidad de modificar ni una sola línea del código fuente real de la aplicación.
  • APIs Públicas de Pruebas: Servicios como JSONPlaceholder, DummyJSON o ReqRes permiten desarrollar y probar la lógica cliente de forma inmediata sin depender de que el backend esté listo.

async function auditarEndpointAPI(url, limiteMs = 3000) {
    console.log(`🔍 Auditando conectividad con: ${url} (Timeout: ${limiteMs}ms)`);
    const t0 = performance.now();

    try {
        const respuesta = await fetch(url, {
            signal: AbortSignal.timeout(limiteMs)
        });

        const tiempoRespuestaMs = Number((performance.now() - t0).toFixed(2));

        if (!respuesta.ok) {
            return {
                url,
                estado: "Error HTTP",
                codigo: respuesta.status,
                statusText: respuesta.statusText,
                latenciaMs: tiempoRespuestaMs,
                diagnostico: "El servidor respondió, pero rechazó la solicitud (código " + respuesta.status + ")."
            };
        }

        return {
            url,
            estado: "OK",
            codigo: respuesta.status,
            latenciaMs: tiempoRespuestaMs,
            diagnostico: "Conexión óptima y datos recibidos sin restricciones CORS."
        };

    } catch (error) {
        const tiempoFalloMs = Number((performance.now() - t0).toFixed(2));

        if (error.name === "TimeoutError") {
            return {
                url,
                estado: "Timeout",
                latenciaMs: tiempoFalloMs,
                diagnostico: `La petición fue cancelada tras superar el límite de ${limiteMs}ms.`
            };
        }

        return {
            url,
            estado: "Fallo de Red / CORS",
            latenciaMs: tiempoFalloMs,
            diagnostico: "Bloqueo por directiva CORS del navegador o servidor inalcanzable (Failed to fetch)."
        };
    }
}

Construye un simulador interactivo completo que represente la arquitectura de la aplicación Tienda Online en React 18, incluyendo: 1) Barra de navegación superior con badge reactivo del carrito, 2) Catálogo en grid con tarjetas de productos y filtro de búsqueda en tiempo real mediante `useState`, 3) Carga asíncrona inicial de datos simulando un efecto secundario con `useEffect`, y 4) Ficha de detalle de producto con opción de retorno al catálogo principal.
💡 Pistas Clave y Procedimiento Guiado
Crea una clase contenedora `ReactStoreSimulator` que maneje la reactividad del estado y ejecute `efectoInicialMontado()` para simular la carga con `useEffect`. Utiliza `\x3C` para escapar cualquier etiqueta HTML en las cadenas JS.
🔍 Desplegar Solución Embebida y Explicación Técnica Clic para Ver/Ocultar
Explicación Técnica: El patrón de arquitectura basada en componentes declarativos, elevación de estado y efectos en React simplifica el desarrollo de SPAs comerciales mantenibles y reactivas.

// Reto 9: Simulador Interactivo de la Aplicación Tienda Online en React 18 (useState y useEffect)
class ReactStoreSimulator {
    constructor(contenedorId) {
        this.contenedor = document.getElementById(contenedorId);
        // Estado reactivo de la aplicación React (useState)
        this.state = {
            productos: [],
            carrito: [],
            cargando: true,
            busqueda: "",
            vistaActual: "catalogo", // 'catalogo' | 'detalle'
            productoSeleccionado: null
        };

        // Simulación de efecto secundario useEffect(() => {}, []) al montar el componente
        this.efectoInicialMontado();
    }

    // Función equivalente al despachador setState() de React para re-renderizar reactivamente
    setState(nuevoEstadoParcial) {
        this.state = { ...this.state, ...nuevoEstadoParcial };
        this.render();
    }

    efectoInicialMontado() {
        console.log("⚛️ [useEffect] Ejecutando efecto de carga inicial de productos desde la API REST...");
        setTimeout(() => {
            const datosApi = [
                { id: 1, nombre: "Portátil React Book 16", precio: 1299, imagen: "💻", descripcion: "Procesador M3 Ultra 16-Core, 32GB RAM DDR5, Pantalla OLED 120Hz. Optimizado para desarrollo con React 18 y Next.js.", categoria: "Ordenadores" },
                { id: 2, nombre: "Teclado Mecánico JSX RGB", precio: 119, imagen: "⌨️", descripcion: "Switches mecánicos táctiles silenciosos, iluminación RGB direccionable por software y cable trenzado USB-C.", categoria: "Periféricos" },
                { id: 3, nombre: "Monitor Curvo Hooks 4K", precio: 449, imagen: "🖥️", descripcion: "Resolución UHD 3840x2160, 144Hz, cobertura 99% sRGB. Visualización multitarea sin parpadeos para desarrolladores.", categoria: "Pantallas" },
                { id: 4, nombre: "Auriculares State HiFi", precio: 179, imagen: "🎧", descripcion: "Audio de alta resolución Hi-Res, cancelación activa de ruido adaptativa y micrófonos duales beamforming.", categoria: "Audio" }
            ];
            this.setState({ productos: datosApi, cargando: false });
        }, 500);
    }

    render() {
        if (!this.contenedor) return;

        if (this.state.cargando) {
            this.contenedor.innerHTML = `
                \x3Cdiv style="padding: 24px; background: #0f172a; color: #38bdf8; font-weight: bold; border-radius: 10px; font-family: sans-serif; text-align: center;"\x3E
                    ⌛ [React useEffect] Cargando productos asíncronos desde API REST...
                \x3C/div\x3E
            `;
            return;
        }

        // 1. Componente Navbar
        const navbarHtml = `
            \x3Cnav style="background: #0f172a; border-bottom: 1px solid #334155; padding: 12px 20px; display: flex; justify-content: space-between; align-items: center; border-radius: 10px 10px 0 0;"\x3E
                \x3Cdiv style="display: flex; align-items: center; gap: 10px;"\x3E
                    \x3Cspan style="font-size: 1.5em;"\x3E⚛️\x3C/span\x3E
                    \x3Cstrong style="color: #f8fafc; font-size: 1.1em;"\x3ETienda React 18 Store\x3C/strong\x3E
                \x3C/div\x3E
                \x3Cdiv style="display: flex; gap: 12px; align-items: center;"\x3E
                    \x3Cbutton id="btn-nav-catalogo" style="background: ${this.state.vistaActual === 'catalogo' ? '#0284c7' : 'transparent'}; color: white; border: none; padding: 6px 12px; border-radius: 6px; cursor: pointer; font-weight: bold; font-size: 0.85em;"\x3E
                        🛒 Catálogo
                    \x3C/button\x3E
                    \x3Cspan style="background: #10b981; color: white; padding: 4px 10px; border-radius: 20px; font-weight: bold; font-size: 0.8em;"\x3E
                        🛒 Carrito (${this.state.carrito.length})
                    \x3C/span\x3E
                \x3C/div\x3E
            \x3C/nav\x3E
        `;

        let cuerpoHtml = "";

        // 2. Componente Vista de Catálogo con Filtro useState
        if (this.state.vistaActual === "catalogo") {
            const productosFiltrados = this.state.productos.filter(p =>
                p.nombre.toLowerCase().includes(this.state.busqueda.toLowerCase())
            );

            cuerpoHtml = `
                \x3Cdiv style="padding: 20px; background: #1e293b; border-radius: 0 0 10px 10px;"\x3E
                    \x3Cdiv style="margin-bottom: 16px; display: flex; justify-content: space-between; align-items: center; gap: 14px;"\x3E
                        \x3Cdiv\x3E
                            \x3Ch2 style="margin: 0; color: #f8fafc; font-size: 1.2em;"\x3ECatálogo de Productos Destacados\x3C/h2\x3E
                            \x3Cp style="margin: 4px 0 0 0; color: #94a3b8; font-size: 0.85em;"\x3ERenderizado reactivo de componentes e inmutabilidad de estado en React 18\x3C/p\x3E
                        \x3C/div\x3E
                        \x3Cinput id="react-search-input" type="text" placeholder="🔍 Filtrar en vivo (useState)..." value="${this.state.busqueda}" style="padding: 8px 14px; border-radius: 8px; border: 1px solid #334155; background: #0f172a; color: white; font-size: 0.85em; width: 220px;" /\x3E
                    \x3C/div\x3E

                    \x3Cdiv style="display: grid; grid-template-columns: repeat(auto-fill, minmax(200px, 1fr)); gap: 14px;"\x3E
                        ${productosFiltrados.map(p => `
                            \x3Cdiv style="background: #0f172a; border: 1px solid #334155; border-radius: 10px; padding: 14px; display: flex; flex-direction: column; justify-content: space-between;"\x3E
                                \x3Cdiv\x3E
                                    \x3Cdiv style="font-size: 3em; text-align: center; margin-bottom: 8px;"\x3E${p.imagen}\x3C/div\x3E
                                    \x3Cspan style="font-size: 0.7em; background: #0284c7; color: white; padding: 2px 6px; border-radius: 4px; font-weight: bold;"\x3E${p.categoria}\x3C/span\x3E
                                    \x3Ch3 style="margin: 8px 0 4px 0; color: #f8fafc; font-size: 1em;"\x3E${p.nombre}\x3C/h3\x3E
                                    \x3Cp style="margin: 0; color: #38bdf8; font-weight: bold; font-size: 1.1em;"\x3E${p.precio} €\x3C/p\x3E
                                \x3C/div\x3E
                                \x3Cdiv style="margin-top: 14px; display: flex; flex-direction: column; gap: 6px;"\x3E
                                    \x3Cbutton class="btn-react-detalle" data-id="${p.id}" style="background: #0284c7; color: white; border: none; padding: 7px; border-radius: 6px; cursor: pointer; font-weight: bold; font-size: 0.82em; width: 100%;"\x3E
                                        🔍 Ver Detalle
                                    \x3C/button\x3E
                                    \x3Cbutton class="btn-react-add" data-id="${p.id}" style="background: #10b981; color: white; border: none; padding: 7px; border-radius: 6px; cursor: pointer; font-weight: bold; font-size: 0.82em; width: 100%;"\x3E
                                        ➕ Añadir al Carrito
                                    \x3C/button\x3E
                                \x3C/div\x3E
                            \x3C/div\x3E
                        `).join('')}
                    \x3C/div\x3E
                \x3C/div\x3E
            `;
        } 
        // 3. Componente Vista de Detalle (ProductoDetalle)
        else if (this.state.vistaActual === "detalle" && this.state.productoSeleccionado) {
            const p = this.state.productoSeleccionado;
            cuerpoHtml = `
                \x3Cdiv style="padding: 20px; background: #1e293b; border-radius: 0 0 10px 10px;"\x3E
                    \x3Cbutton id="btn-react-volver" style="background: #334155; color: white; border: none; padding: 6px 12px; border-radius: 6px; cursor: pointer; margin-bottom: 16px; font-size: 0.85em; font-weight: bold;"\x3E
                        ← Volver al Catálogo
                    \x3C/button\x3E
                    \x3Cdiv style="background: #0f172a; border: 1px solid #38bdf8; border-radius: 12px; padding: 20px; display: grid; grid-template-columns: 80px 1fr; gap: 20px; align-items: start;"\x3E
                        \x3Cdiv style="font-size: 3.5em; text-align: center; background: #1e293b; border-radius: 10px; padding: 10px;"\x3E${p.imagen}\x3C/div\x3E
                        \x3Cdiv\x3E
                            \x3Cdiv style="display: flex; gap: 8px; align-items: center; margin-bottom: 6px;"\x3E
                                \x3Cspan style="font-size: 0.7em; background: #0284c7; color: white; padding: 2px 8px; border-radius: 4px; font-weight: bold;"\x3E${p.categoria}\x3C/span\x3E
                            \x3C/div\x3E
                            \x3Ch2 style="margin: 0 0 8px 0; color: #f8fafc; font-size: 1.4em;"\x3E${p.nombre}\x3C/h2\x3E
                            \x3Cp style="margin: 0 0 12px 0; color: #38bdf8; font-weight: bold; font-size: 1.3em;"\x3E${p.precio} €\x3C/p\x3E
                            \x3Cp style="margin: 0; color: #cbd5e1; font-size: 0.9em; line-height: 1.5; background: #1e293b; padding: 12px; border-radius: 8px; border-left: 3px solid #38bdf8;"\x3E
                                ${p.descripcion}
                            \x3C/p\x3E
                            \x3Cdiv style="margin-top: 16px;"\x3E
                                \x3Cbutton class="btn-react-add" data-id="${p.id}" style="background: #10b981; color: white; border: none; padding: 10px 18px; border-radius: 6px; cursor: pointer; font-weight: bold; font-size: 0.9em;"\x3E
                                    🛒 Añadir al Carrito de React
                                \x3C/button\x3E
                            \x3C/div\x3E
                        \x3C/div\x3E
                    \x3C/div\x3E
                \x3C/div\x3E
            `;
        }

        this.contenedor.innerHTML = navbarHtml + cuerpoHtml;
        this.bindEvents();
    }

    bindEvents() {
        const btnNavCat = this.contenedor.querySelector("#btn-nav-catalogo");
        if (btnNavCat) {
            btnNavCat.onclick = () => {
                this.setState({ vistaActual: "catalogo" });
            };
        }

        const btnVolver = this.contenedor.querySelector("#btn-react-volver");
        if (btnVolver) {
            btnVolver.onclick = () => {
                this.setState({ vistaActual: "catalogo" });
            };
        }

        const searchInput = this.contenedor.querySelector("#react-search-input");
        if (searchInput) {
            searchInput.oninput = (e) => {
                this.setState({ busqueda: e.target.value });
            };
        }

        const btnsDetalle = this.contenedor.querySelectorAll(".btn-react-detalle");
        btnsDetalle.forEach(btn => {
            btn.onclick = (e) => {
                const id = Number(e.currentTarget.dataset.id);
                const producto = this.state.productos.find(p => p.id === id);
                if (producto) {
                    this.setState({ productoSeleccionado: producto, vistaActual: "detalle" });
                }
            };
        });

        const btnsAdd = this.contenedor.querySelectorAll(".btn-react-add");
        btnsAdd.forEach(btn => {
            btn.onclick = (e) => {
                const id = Number(e.currentTarget.dataset.id);
                const producto = this.state.productos.find(p => p.id === id);
                if (producto) {
                    this.setState({ carrito: [...this.state.carrito, producto] });
                }
            };
        });
    }
}
