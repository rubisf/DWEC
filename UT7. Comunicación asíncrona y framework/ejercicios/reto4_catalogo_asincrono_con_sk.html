Reto 4: Catálogo Asíncrono con Skeleton Loading, Renderizado Dinámico y Manejo de Errores

📝 Enunciado:

Diseña un componente que consuma una lista de productos desde una URL de prueba. Debe mostrar una estructura de Skeleton Loading mientras la petición esté activa (simulando 1 segundo de latencia con `setTimeout`), renderizar las tarjetas de productos con `DocumentFragment` y `textContent` en caso de éxito, y si la URL es incorrecta o falla, renderizar una tarjeta de error estilizada con un botón interactivo de reintento.

💡 Pistas: Usa una función asíncrona. Inyecta HTML con clase skeleton antes del fetch. Envuelve en try/catch y añade un event listener al botón de reintentar para volver a ejecutar la función.
Salida dual: Terminal interactivo y Consola F12

La robusta gestión de los estados de carga, éxito y error diferencia las aplicaciones profesionales de los prototipos informales, garantizando resiliencia frente a caídas de red.

class CatalogoAsincronoUI {
    constructor(contenedorId, apiUrl) {
        this.contenedor = document.getElementById(contenedorId);
        this.apiUrl = apiUrl;
    }

    mostrarCargando() {
        this.contenedor.innerHTML = \`
            <div style="display: grid; grid-template-columns: 1fr 1fr; gap: 10px; font-family: sans-serif;">
                <div style="height: 80px; background: #e2e8f0; border-radius: 8px; animation: pulse 1.5s infinite;"></div>
                <div style="height: 80px; background: #e2e8f0; border-radius: 8px; animation: pulse 1.5s infinite;"></div>
            </div>
            <p style="text-align: center; color: #64748b; font-size: 0.8em; margin-top: 6px;">Cargando datos remotos...</p>
        \`;
    }

    mostrarError(mensaje) {
        this.contenedor.innerHTML = \`
            <div style="padding: 16px; background: #fef2f2; border: 1px solid #f87171; border-radius: 8px; color: #b91c1c; font-family: sans-serif;">
                <strong>⚠️ Fallo de Conexión:</strong> \${mensaje}
                <div style="margin-top: 10px;">
                    <button id="btn-reintentar" style="background: #dc2626; color: white; border: none; padding: 6px 12px; border-radius: 6px; cursor: pointer;">
                        🔄 Reintentar Ahora
                    </button>
                </div>
            </div>
        \`;
        this.contenedor.querySelector("#btn-reintentar").onclick = () => this.cargar();
    }

    mostrarDatos(items) {
        this.contenedor.replaceChildren(); // Limpiar
        const fragment = document.createDocumentFragment();

        items.forEach(item => {
            const card = document.createElement("div");
            card.style.cssText = "border: 1px solid #cbd5e1; padding: 12px; border-radius: 8px; margin-bottom: 8px; background: #fff;";

            const tit = document.createElement("h4");
            tit.style.margin = "0 0 4px 0";
            tit.textContent = item.title || item.nombre; // Seguro

            const desc = document.createElement("p");
            desc.style.margin = "0";
            desc.style.fontSize = "0.85em";
            desc.style.color = "#64748b";
            desc.textContent = item.body || item.descripcion || "Sin descripción disponible.";

            card.append(tit, desc);
            fragment.appendChild(card);
        });

        this.contenedor.appendChild(fragment);
    }

    async cargar() {
        this.mostrarCargando();
        try {
            // Simular retardo de red de 600ms para apreciar el skeleton
            await new Promise(r => setTimeout(r, 600));

            const res = await fetch(this.apiUrl);
            if (!res.ok) throw new Error(\`HTTP \${res.status} (\${res.statusText})\`);

            const datos = await res.json();
            this.mostrarDatos(datos.slice(0, 4));
        } catch (err) {
            this.mostrarError(err.message);
        }
    }
}
