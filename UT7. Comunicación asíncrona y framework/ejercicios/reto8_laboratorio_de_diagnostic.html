Reto 8: Laboratorio de Diagnóstico de Errores de Red y Simulación de Fallos CORS

📝 Enunciado:

Escribe una función llamada `auditarEndpointAPI(url)` que intente realizar una petición con `fetch()` y analice minuciosamente el resultado. Si la petición falla, debe discriminar si el fallo se debió a un error de conexión/CORS (`TypeError: Failed to fetch`), a una cancelación por timeout con `AbortController` (`TimeoutError`), o a una respuesta con código de error HTTP (4xx o 5xx), registrando en consola un informe detallado con el tiempo de latencia medido mediante `performance.now()`.

💡 Pistas: Usa try/catch. Comprueba error.name === "TimeoutError" para tiempos agotados. Si res.ok es false, lee res.status. Mide tiempo con performance.now().

La capacidad de clasificar con precisión la causa de un fallo asíncrono permite proporcionar al usuario una solución adecuada (revisar la conexión, reintentar o reportar un error del servidor).

async function auditarEndpointAPI(url, limiteMs = 3000) {
    console.log(\`🔍 Auditando conectividad con: \${url} (Timeout: \${limiteMs}ms)\`);
    const t0 = performance.now();

    try {
        const respuesta = await fetch(url, {
            signal: AbortSignal.timeout(limiteMs)
        });

        const tiempoRespuestaMs = Number((performance.now() - t0).toFixed(2));

        if (!respuesta.ok) {
            return {
                url,
                estado: "Error HTTP",
                codigo: respuesta.status,
                statusText: respuesta.statusText,
                latenciaMs: tiempoRespuestaMs,
                diagnostico: "El servidor respondió, pero rechazó la solicitud (código " + respuesta.status + ")."
            };
        }

        return {
            url,
            estado: "OK",
            codigo: respuesta.status,
            latenciaMs: tiempoRespuestaMs,
            diagnostico: "Conexión óptima y datos recibidos sin restricciones CORS."
        };

    } catch (error) {
        const tiempoFalloMs = Number((performance.now() - t0).toFixed(2));

        if (error.name === "TimeoutError") {
            return {
                url,
                estado: "Timeout",
                latenciaMs: tiempoFalloMs,
                diagnostico: \`La petición fue cancelada tras superar el límite de \${limiteMs}ms.\`
            };
        }

        return {
            url,
            estado: "Fallo de Red / CORS",
            latenciaMs: tiempoFalloMs,
            diagnostico: "Bloqueo por directiva CORS del navegador o servidor inalcanzable (Failed to fetch)."
        };
    }
}

// Prueba con endpoint válido
auditarEndpointAPI("https://jsonplaceholder.typicode.com/posts/1")
    .then(informe => console.table([informe]));
