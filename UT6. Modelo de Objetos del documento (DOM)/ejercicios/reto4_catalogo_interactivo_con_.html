Reto 4: Catálogo Interactivo con Metadatos data-* y Filtrado Reactivo por Atributos

📝 Enunciado:

Construye un módulo para filtrar un catálogo de cursos. Cada tarjeta de curso posee atributos `data-categoria` (ej. "frontend", "backend", "seguridad") y `data-nivel` ("iniciacion", "avanzado"). Crea una función `filtrarCatalogo(categoria, nivelMinimo)` que recorra todos los artículos del catálogo con `querySelectorAll()`, lea los metadatos con `elemento.dataset`, oculte con `elemento.hidden = true` aquellos que no coincidan y muestre con `elemento.hidden = false` los que satisfagan los criterios.

💡 Pistas: Lee articulo.dataset.categoria y articulo.dataset.nivel. Compara los valores y actualiza la propiedad booleana articulo.hidden.

El uso de dataset combinado con la propiedad nativa hidden permite crear sistemas de filtrado de contenido instantáneos y declarativos sin tocar clases complejas.

function filtrarCatalogoCursos(categoriaFiltro, nivelFiltro) {
    const articulos = document.querySelectorAll("article.tarjeta-curso");
    let visibles = 0;

    articulos.forEach(art => {
        // Extracción de metadatos desde dataset
        const categoria = art.dataset.categoria;
        const nivel = art.dataset.nivel;

        const coincideCategoria = !categoriaFiltro || categoriaFiltro === "todas" || categoria === categoriaFiltro;
        const coincideNivel = !nivelFiltro || nivelFiltro === "todos" || nivel === nivelFiltro;

        if (coincideCategoria && coincideNivel) {
            art.hidden = false;
            visibles++;
        } else {
            art.hidden = true;
        }
    });

    console.log(\`Filtrado completado: \${visibles}/\${articulos.length} cursos visibles.\`);
    return visibles;
}
