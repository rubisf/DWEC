Reto 5: Monitor de Mutaciones del DOM en Tiempo Real con MutationObserver

📝 Enunciado:

Implementa un sistema de auditoría del DOM que vigile un contenedor `#panel-notificaciones`. Mediante `MutationObserver`, detecta cuando se añada un nuevo nodo hijo de tipo elemento y comprueba si posee la clase `"notificacion-urgente"`. En caso afirmativo, emite un aviso sonoro o alerta en consola, imprime el contenido del texto insertado y registra la marca de tiempo exacta del cambio.

💡 Pistas: En el callback de MutationObserver, itera sobre mutacion.addedNodes. Comprueba nodo.nodeType === Node.ELEMENT_NODE y nodo.classList.contains("notificacion-urgente").

MutationObserver proporciona un mecanismo desacoplado para interceptar y validar cambios en la estructura del documento en tiempo real sin interferir en el código que produce la inserción.

function auditarNotificaciones(contenedor) {
    const observer = new MutationObserver((mutaciones) => {
        for (const mutacion of mutaciones) {
            if (mutacion.type === "childList") {
                mutacion.addedNodes.forEach(nodo => {
                    // Filtrar sólo nodos de elemento
                    if (nodo.nodeType === Node.ELEMENT_NODE) {
                        const esUrgente = nodo.classList.contains("notificacion-urgente");
                        const mensaje = nodo.textContent.trim();
                        const hora = new Date().toLocaleTimeString();

                        if (esUrgente) {
                            console.warn(\`🚨 [\${hora}] ALERTA URGENTE DETECTADA EN DOM: "\${mensaje}"\`);
                        } else {
                            console.log(\`ℹ️ [\${hora}] Notificación estándar añadida: "\${mensaje}"\`);
                        }
                    }
                });
            }
        }
    });

    observer.observe(contenedor, { childList: true, subtree: false });
    console.log("Vigilante MutationObserver activo en:", contenedor.id);

    return observer;
}
