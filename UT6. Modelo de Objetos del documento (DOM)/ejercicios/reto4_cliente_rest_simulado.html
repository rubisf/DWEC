🎯 Reto 4: Especificación Semántica de Endpoints REST

1. GET /api/v1/alumnos -> Listar todos los alumnos
2. POST /api/v1/alumnos -> Crear un nuevo alumno
3. GET /api/v1/alumnos/42 -> Obtener detalle del alumno ID 42
4. PATCH /api/v1/alumnos/42 -> Modificar parcialmente el teléfono del alumno
5. DELETE /api/v1/alumnos/42 -> Dar de baja al alumno ID 42
