Reto 4: Formulario de Registro Dinámico con Campos Condicionales y Bloqueo de Envío

📝 Enunciado:

Diseña la lógica de un formulario de registro donde el usuario seleccione si es "Particular" o "Empresa" mediante un select. Si selecciona "Empresa", muestra dinámicamente un campo de texto adicional para el "CIF" y hazlo obligatorio. Intercepta el evento `submit` con `e.preventDefault()`, extrae todos los datos usando `FormData`, valida que los campos requeridos estén completos y muestra el resultado en formato JSON en consola.

💡 Pistas: Escucha el evento change en el select. Modifica la visibilidad del campo CIF cambiando su estilo display o clase hidden. Usa new FormData(form) en el submit.

La gestión de campos condicionales en formularios mejora la conversión del usuario mostrando únicamente los campos pertinentes según sus respuestas previas.

function configurarFormularioRegistro(formulario, selectTipo, campoCifContenedor, inputCif) {
    // 1. Mostrar/ocultar campo CIF dinámicamente
    selectTipo.addEventListener("change", () => {
        if (selectTipo.value === "empresa") {
            campoCifContenedor.style.display = "block";
            inputCif.required = true;
            inputCif.focus();
        } else {
            campoCifContenedor.style.display = "none";
            inputCif.required = false;
            inputCif.value = "";
        }
    });

    // 2. Control del envío del formulario
    formulario.addEventListener("submit", (e) => {
        e.preventDefault(); // Impide recarga de página

        const formData = new FormData(formulario);
        const payload = Object.fromEntries(formData.entries());

        console.log("Formulario validado y procesado localmente:");
        console.table(payload);
    });
}
