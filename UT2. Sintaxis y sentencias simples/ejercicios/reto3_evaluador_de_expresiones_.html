Reto 3: Evaluador de Expresiones y Fallbacks con Operadores Modernos

📝 Enunciado:

Dada una lista de pedidos donde algunos clientes no tienen registrada dirección de entrega, otros tienen coste de envío 0€ (envío gratis) y otros datos nulos, crea una función que procese cada pedido calculando el total a pagar (importe base + coste de envío) y devuelva la calle de entrega. Asegúrate de que el envío gratis de 0€ se respete correctamente mediante `??` y no se sustituya por la tarifa base de 4.99€.

💡 Pistas: Utiliza pedido.envio ?? 4.99 para evitar sobreescribir el 0 con 4.99. Utiliza pedido.cliente?.direccion?.calle ?? "Recogida en tienda" para evitar ReferenceError.

El operador nullish coalescing previene el error común de tratar el 0 o false como datos faltantes, y optional chaining evita que el script falle por acceder a propiedades de undefined.

function procesarPedidosExpress(pedidos) {
    return pedidos.map(pedido => {
        // Fallback seguro de envío respetando el 0€
        const costeEnvio = pedido.envio ?? 4.99;
        const total = Number((pedido.base + costeEnvio).toFixed(2));
        
        // Extracción segura de dirección profunda
        const direccionEntrega = pedido.cliente?.direccion?.calle 
            ? \`\${pedido.cliente.direccion.calle}, \${pedido.cliente.direccion.ciudad ?? 'S/C'}\` 
            : "Recogida en Tienda Central";

        return {
            id: pedido.id,
            total,
            envio: costeEnvio === 0 ? "Gratis" : \`\${costeEnvio}€\`,
            direccion: direccionEntrega
        };
    });
}

// Datos de prueba con casos límite
const pedidos = [
    { id: 1, base: 50, envio: 0, cliente: { direccion: { calle: "Gran Vía 28", ciudad: "Madrid" } } },
    { id: 2, base: 25, envio: null, cliente: null }, // Sin cliente ni envío
    { id: 3, base: 100, envio: 12.5, cliente: { direccion: null } } // Cliente sin dirección
];

console.table(procesarPedidosExpress(pedidos));
