Reto 4: Motor de Reglas de Descuento y Filtrado de Stock con Bucles e Interrupciones

📝 Enunciado:

Escribe una función que procese un inventario de artículos aplicando descuentos según la categoría con una estructura `switch`. Recorre el inventario con `for...of`. Si un producto tiene stock 0, salta al siguiente con `continue`. Si se detecta un artículo con precio negativo (error de base de datos), interrumpe el procesamiento global con `break` y notifica la anomalía.

💡 Pistas: Declara un array de artículos. Usa switch(articulo.categoria) para fijar el porcentaje de descuento. Controla articulo.stock === 0 con continue y articulo.precio < 0 con break.

La combinación de switch con sentencias continue y break permite estructurar flujos de validación robustos y eficientes en colecciones de datos comerciales.

function procesarInventario(articulos) {
    const catalogoProcesado = [];
    let errorCritico = false;

    for (const prod of articulos) {
        // Control de anomalía crítica: interrupción con break
        if (prod.precio < 0) {
            console.error("ALERTA CRÍTICA: Precio negativo detectado en ID " + prod.id + ". Proceso detenido.");
            errorCritico = true;
            break;
        }

        // Producto sin existencias: salto con continue
        if (prod.stock === 0) {
            console.warn("Stock agotado para " + prod.nombre + ". Omitiendo de catálogo activo.");
            continue;
        }

        let descuento = 0;
        switch (prod.categoria) {
            case "informatica":
                descuento = 0.10; // 10%
                break;
            case "telefonia":
                descuento = 0.15; // 15%
                break;
            case "accesorios":
                descuento = 0.20; // 20%
                break;
            default:
                descuento = 0.05; // 5% base
        }

        const precioFinal = Number((prod.precio * (1 - descuento)).toFixed(2));
        catalogoProcesado.push({
            id: prod.id,
            nombre: prod.nombre,
            precioOriginal: prod.precio,
            precioFinal,
            ahorro: Number((prod.precio - precioFinal).toFixed(2))
        });
    }

    return { catalogoProcesado, estado: errorCritico ? "Interrumpido con Errores" : "Procesado con Éxito" };
}
