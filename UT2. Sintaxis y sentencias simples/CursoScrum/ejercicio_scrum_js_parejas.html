🛠️ Práctica Ágil: Mini Sprint Scrum con JavaScript Sencillo

Objetivo: Experimentar un ciclo Scrum real en parejas creando una aplicación web interactiva (TaskSprint JS). Aprenderéis a distribuir roles, desglosar la Pila de Producto en Historias de Usuario, estimar tiempos con Planning Poker, gestionar un Tablero Kanban y entregar un incremento funcional en un Sprint de 45 minutos.

👥 1. Distribución de Roles por Parejas (Grupos de 2)

Cada pareja se dividirá los roles de Scrum. Ambos estudiantes actuarán como Desarrolladores (Developers) para escribir el código JavaScript, pero cada uno asumirá la responsabilidad de un rol de facilitación:

👤 ESTUDIANTE A Product Owner + Dev
  • 📌 Responsabilidad Ágil (PO): Redacta los Criterios de Aceptación, prioriza las Historias de Usuario y aprueba el resultado final verificando la Definition of Done (DoD).
  • 💻 Responsabilidad Técnica (Dev 1): Programa el Formulario de Alta de Tareas (US-01) y la Sección de Métricas y Contadores (US-04).
🛡️ ESTUDIANTE B Scrum Master + Dev
  • 📌 Responsabilidad Ágil (SM): Dibuja/gestiona el Tablero Kanban (Por Hacer ➔ En Proceso ➔ Hecho), controla el tiempo del Sprint (Timebox) y lidera la Daily de 2 minutos.
  • 💻 Responsabilidad Técnica (Dev 2): Programa la lista dinámica con cambio de estado de tareas (US-02) y los botones de filtro por estado (US-03).

📦 2. Pila de Producto (Product Backlog - TaskSprint JS)

La aplicación consiste en un mini gestor de tareas sencillo en JavaScript. El Product Owner debe revisar las 4 Historias de Usuario:

US-01 • Alta de Tarea Asignado: Estudiante A

"Como alumno, quiero introducir el texto de una tarea en un campo de texto y pulsar 'Añadir' para guardarla en el sistema."

🎯 Criterio de Aceptación: Si el campo está vacío, no se añade nada. El input se limpia tras añadir.
US-02 • Renderizado y Estado Asignado: Estudiante B

"Como usuario, quiero ver la lista de tareas agregadas y poder pulsar un botón para alternar su estado entre 'Pendiente' y 'Completada'."

🎯 Criterio de Aceptación: Las tareas completadas cambian visualmente (ej. texto tachado o fondo verde).
US-03 • Filtros de Vista Asignado: Estudiante B

"Como usuario, quiero pulsar botones de filtro ('Todas', 'Pendientes', 'Completadas') para ver solo las tareas correspondientes."

🎯 Criterio de Aceptación: Al pulsar cada botón, se filtra dinámicamente el array con Array.prototype.filter().
US-04 • Resumen de Métricas Asignado: Estudiante A

"Como usuario, quiero ver un contador superior que indique el total de tareas y cuántas han sido completadas (ej: '2 de 5 completadas')."

🎯 Criterio de Aceptación: El contador se recalcula automáticamente cada vez que se añade o cambia una tarea.

⏱️ 3. Fases de la Dinámica de la Práctica (45 Minutos Totales)

Fase 1: Sprint Planning y Planning Poker por Parejas (10 minutos)

  1. Ambos estudiantes leen juntos las 4 Historias de Usuario.
  2. Realizan una estimación con Planning Poker asignando Puntos de Historia (1, 2, 3 o 5) a cada US según su complejidad.
  3. Acuerdan la Definition of Done (DoD): "Código ejecutable sin errores en consola, variables declaradas con let/const y funcionalidad probada en navegador."
  4. El Scrum Master (Estudiante B) crea las 4 tarjetas en el Tablero Kanban (físico en papel o digital).

Fase 2: Ejecución del Sprint (25 minutos)

  1. Cada desarrollador programa sus funciones JavaScript correspondientes (Estudiante A: US-01 y US-04; Estudiante B: US-02 y US-03).
  2. Daily Standup Express (Minuto 12 del Sprint - 2 minutos): Se realiza una breve reunión de 2 min de pie respondiendo:
    • ¿Qué función tengo ya lista?
    • ¿Qué voy a programar ahora?
    • ¿Tengo algún bloqueo de integración de código?
  3. A medida que se completa una US, se mueve en el Kanban de En Proceso ➔ Hecho.

Fase 3: Sprint Review y Retrospectiva Kaizen (10 minutos)

  1. Sprint Review (5 min): La pareja demuestra la aplicación funcionando al profesor o a otra pareja de clase. El PO valida que cumple la DoD.
  2. Retrospectiva (5 min): La pareja responde a 3 preguntas de mejora continua:
    • ¿Acertamos en la estimación de Puntos de Historia?
    • ¿Tuvimos problemas al integrar el código de ambos en el mismo fichero HTML/JS?
    • ¿Qué acuerdo técnico tomaríamos para el próximo Sprint?

💻 4. Plantilla de Código Base (TaskSprint JS)

Podéis utilizar esta plantilla HTML/JS minimalista para trabajar juntos en la solución: 

<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8"/>
  <title>TaskSprint JS - Ejercicio Scrum</title>
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="bg-slate-900 text-slate-100 p-6 font-sans">

  <div class="max-w-md mx-auto bg-slate-800 border border-slate-700 rounded-2xl p-6 space-y-4 shadow-xl">
    <h2 class="text-lg font-bold text-amber-400">⚡ TaskSprint JS</h2>

    <!-- US-04: Métricas (Estudiante A) -->
    <div id="metricas" class="text-xs text-slate-400 font-semibold bg-slate-900 p-3 rounded-xl border border-slate-700">
      📊 Cargando estadísticas...
    </div>

    <!-- US-01: Formulario de Alta (Estudiante A) -->
    <form id="form-tarea" class="flex gap-2">
      <input type="text" id="input-tarea" placeholder="Nueva tarea..." class="flex-1 bg-slate-900 border border-slate-700 rounded-xl px-3 py-2 text-xs text-white focus:outline-none focus:border-amber-400"/>
      <button type="submit" class="bg-amber-500 hover:bg-amber-600 text-slate-950 font-bold px-4 py-2 rounded-xl text-xs transition-colors">Añadir</button>
    </form>

    <!-- US-03: Botones de Filtro (Estudiante B) -->
    <div class="flex gap-1 text-xs">
      <button id="btn-todas" class="flex-1 bg-indigo-600 hover:bg-indigo-700 text-white font-semibold py-1.5 rounded-lg transition-colors">Todas</button>
      <button id="btn-pendientes" class="flex-1 bg-slate-700 hover:bg-slate-600 text-slate-200 font-semibold py-1.5 rounded-lg transition-colors">Pendientes</button>
      <button id="btn-completadas" class="flex-1 bg-slate-700 hover:bg-slate-600 text-slate-200 font-semibold py-1.5 rounded-lg transition-colors">Completadas</button>
    </div>

    <!-- US-02: Lista Dinámica (Estudiante B) -->
    <ul id="lista-tareas" class="space-y-2 pt-2">
      <!-- Las tareas se dibujan dinámicamente aquí -->
    </ul>
  </div>

  <script>
    // Estado global de la aplicación (Array de Objetos)
    const tareas = [
      { id: 1, texto: 'Aprender roles de Scrum', completada: true },
      { id: 2, texto: 'Estimar historias con Planning Poker', completada: false }
    ];

    let filtroActual = 'todas'; // 'todas' | 'pendientes' | 'completadas'

    // ==========================================
    // CÓDIGO DEL ESTUDIANTE A (US-01 y US-04)
    // ==========================================
    function actualizarMetricas() {
      const total = tareas.length;
      const completadas = tareas.filter(t => t.completada).length;
      const elMetricas = document.getElementById('metricas');
      elMetricas.textContent = `📊 Estado del Sprint: ${completadas} de ${total} tareas completadas`;
    }

    document.getElementById('form-tarea').addEventListener('submit', (e) => {
      e.preventDefault();
      const input = document.getElementById('input-tarea');
      const texto = input.value.trim();
      if (!texto) return;

      tareas.push({ id: Date.now(), texto: texto, completada: false });
      input.value = '';
      
      renderizar();
      actualizarMetricas();
    });

    // ==========================================
    // CÓDIGO DEL ESTUDIANTE B (US-02 y US-03)
    // ==========================================
    function renderizar() {
      const lista = document.getElementById('lista-tareas');
      lista.innerHTML = '';

      let tareasFiltradas = tareas;
      if (filtroActual === 'pendientes') tareasFiltradas = tareas.filter(t => !t.completada);
      if (filtroActual === 'completadas') tareasFiltradas = tareas.filter(t => t.completada);

      tareasFiltradas.forEach(t => {
        const li = document.createElement('li');
        li.className = `flex items-center justify-between p-3 rounded-xl border text-xs ${t.completada ? 'bg-emerald-950/40 border-emerald-800/60 text-emerald-300 line-through' : 'bg-slate-900 border-slate-700 text-slate-200'}`;
        
        li.innerHTML = `
          ${t.texto}
          
        `;
        lista.appendChild(li);
      });
    }

    function alternarEstado(id) {
      const tarea = tareas.find(t => t.id === id);
      if (tarea) {
        tarea.completada = !tarea.completada;
        renderizar();
        actualizarMetricas();
      }
    }

    document.getElementById('btn-todas').addEventListener('click', () => { filtroActual = 'todas'; renderizar(); });
    document.getElementById('btn-pendientes').addEventListener('click', () => { filtroActual = 'pendientes'; renderizar(); });
    document.getElementById('btn-completadas').addEventListener('click', () => { filtroActual = 'completadas'; renderizar(); });

    // Inicialización al cargar la página
    renderizar();
    actualizarMetricas();
  </script>
</body>
</html>
