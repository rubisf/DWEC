Bienvenido al repositorio oficial del módulo profesional de **Desarrollo Web en Entorno Cliente (DWEC)** del Ciclo Formativo de Grado Superior en **Desarrollo de Aplicaciones Web (DAW)**.

Este proyecto reúne una suite didáctica completa, interactiva y estructurada que abarca desde los fundamentos de ejecución en el navegador hasta la construcción de aplicaciones web dinámicas con comunicación asíncrona y frameworks modernos.

---

## 📚 Estructura Curricular

El contenido está organizado en 7 Unidades Técnicas (UT) completamente desarrolladas:

| Unidad | Título | Descripción Destacada |
| :---: | :--- | :--- |
| **UT1** | ⚡ **Introducción a JavaScript y Mecanismos de Ejecución** | Arquitectura web de 3 capas, modelo *Sandbox*, características del lenguaje y laboratorio de inclusión de scripts (`LlamadasJS`). |
| **UT2** | 📝 **Sintaxis y Sentencias Simples** | Estructuras de control, operadores, ámbitos de variable (`var`, `let`, `const`) y buenas prácticas de código. |
| **UT3** | 🧮 **Objetos Predefinidos del Lenguaje** | Tratamiento de cadenas, fechas (`Date`), matemáticas (`Math`), expresiones regulares y manipulación numérica. |
| **UT4** | 🎯 **Funciones, Arrays y Estructuras Avanzadas** | Programación funcional, métodos iterativos de arrays (`map`, `filter`, `reduce`), colecciones y objetos. |
| **UT5** | 🖱️ **Eventos y Formularios** | Manejo del *Event Loop*, escuchadores de eventos, delegación, validación de formularios y API HTML5. |
| **UT6** | 🌳 **Modelo de Objetos del Documento (DOM)** | Selección, modificación, creación de elementos DOM (`innerHTML`, `createElement`), estilos dinámicos y fragmentos. |
| **UT7** | 🌐 **Comunicación Asíncrona y Frameworks Modernos** | Peticiones asíncronas (`Fetch API`, `Promises`, `Async/Await`), JSON y fundamentos de **React SPA** (JSX, componentes y estado). |

---

## 🛠️ Componentes Didácticos Incluidos

Cada Unidad Técnica dispone de un conjunto integrado de recursos interactivos:

- 📊 **`presentacion.html`**: Presentación web interactiva basada en **Reveal.js** con diseño de alto contraste (*GitHub Dark High Contrast*), diagramas de arquitectura y ejemplos de código resaltados.
- 🧪 **`ejercicios.html`**: Visor unificado de retos teóricos y prácticas guiadas con descripciones, pistas y soluciones probadas.
- 💻 **`ejercicios/`**: Colección de archivos HTML/JS independientes y ejecutables para cada reto de la unidad.
- 🔬 **Laboratorio Práctico (`LlamadasJS`)**: Ejemplos reales en vivo (`web1.html` a `web5.html`) demostrando el comportamiento de `<script>` en `<head>`, en `</body>`, el uso de `defer` y scripts externos `.js`.

## 🖥️ Acceso y Ejecución

No se requiere ningún entorno de compilación ni servidor pesado para explorar el repositorio:

1. Clona o descarga este repositorio:
   ```bash
   git clone https://github.com/rubisf/DWEC.git
   ```
2. Abre el archivo **`index.html`** en cualquier navegador web moderno (Chrome, Edge, Firefox, Safari).
3. Utiliza el **Dashboard Principal** para navegar directamente a las presentaciones o visores de ejercicios de cada unidad.

## 🎨 Características Técnicas del Proyecto

- **HTML5 & CSS3 Responsive**: Interfaz adaptativa optimizada para proyectores, pantallas de escritorio y dispositivos móviles.
- **Sin Dependencias Complejas**: Todo el contenido es directamente interpretable por el navegador web.
- **Estilo de Alto Contraste**: Diseñado con paletas contrastadas para facilitar la docencia y el aprendizaje visual.
